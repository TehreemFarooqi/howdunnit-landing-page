# howdunnit — landing page

The static landing page for howdunnit, a free, open-source, local-first Windows meeting sidekick for developers.

## Preview

Open `index.html` directly, or serve this directory with any static file server. No build step, dependencies, analytics, or third-party assets are used.

The early-access form expects an approved, CORS-enabled HTTPS form endpoint that accepts `multipart/form-data` in its `data-signup-endpoint` attribute. Until an endpoint is configured, it displays an explicit message instead of claiming a signup succeeded. Do not publish a real signup form until its destination and email handling are configured.
