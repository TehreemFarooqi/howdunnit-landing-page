# howdunnit — landing page

The static landing page for [howdunnit](https://github.com/TehreemFarooqi/howdunnit), a free, open-source, local-first Windows meeting sidekick for developers.

## Preview

Open `index.html` directly, or serve this directory with any static file server. No build step, dependencies, analytics, or third-party assets are used.

## Publish

This site is published with GitHub Pages at <https://tehreemfarooqi.github.io/howdunnit-landing-page/>.
